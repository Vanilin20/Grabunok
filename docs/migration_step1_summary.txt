БАНДА — ПЕРЕНЕСЕННЯ З GODOT У UNITY
Крок 1 з 3: головне меню, екрани, живий фон
Дата: 12.11.2026
Рушій: Unity 6.3 LTS (6000.3.7f1), URP 2D, uGUI + TextMeshPro, Input System
Джерело: github.com/Vanilin20/Grabunok (Godot 4.7)

============================================================
1. ДОСТУП ДО UNITY
============================================================
- Unity MCP підключений: Claude може створювати об'єкти, запускати Play,
  натискати кнопки, читати консоль і робити скріншоти прямо в редакторі.
- Обмеження: коли вікно Unity без фокусу, Game view не оновлюється,
  тому скріншоти з UI робляться рендером камери в текстуру.

============================================================
2. ЩО ПЕРЕНЕСЕНО
============================================================
Арт і звук (скопійовано з Godot-репозиторію):
- Assets/Art/Menu   — шари міста, банда (стрічки кадрів), вивіска, потяг, карти нормалей
- Assets/Art/Fx     — дощ, бризки, блискавка, вогні антен (+ згенерована radial.png)
- Assets/Art/UI     — 9-slice кнопки, поля, панель (+ згенерована fill.png)
- Assets/Art/Fonts  — Press Start 2P (TMP-шрифт, растр без згладжування, кирилиця вшита)
- Assets/Audio      — дощ, місто, гудіння неону, грім, клік, відмова
- Assets/Data/menu_layout.json — розкладка фону (перетворена з Godot-формату)

Живий фон (нічне місто з даху):
- 5 планів з паралаксом (миша на ПК / нахил телефона)
- хмари, що пливуть; потяг на віадуці
- неонова вивіска «БАНДА»: літери збоять, «Д» частіше; світло вивіски збоїть разом з нею
- вогні на антенах, мерехтіння лампи над дверима й неону бару
- ліхтарик ватажка, що ледь гуляє в руці
- дощ у 2 шари + бризки на даху
- блискавка раз на 20–30 с (подвійний спалах + грім)
- освітлення Light2D з картами нормалей, Bloom для неону, віньєтка
- банда на окремому сортувальному шарі (Gang), передній план — шар Front

Екрани інтерфейсу:
- Головне меню: ім'я, «Створити кімнату», «Приєднатися», «Тест датчиків»
  (вимкнені кнопки пояснюють себе: «! БРАКУЄ ІМЕНІ»)
- Вхід у кімнату: код з 4 цифр, IP вручну, «Назад»
- Лобі: код кімнати, список банди, вибір ролі (заблоковані ролі з номером етапу), старт
- Справа: ЯВНА ЗАГЛУШКА з трьома варіантами фіналу
- Підсумок: результат, час, тривога, помилки на сейфі
- Сповіщення (toast) знизу екрана, звуки кнопок

============================================================
3. СКРИПТИ (Assets/Scripts)
============================================================
Core/
  Palette.cs            — палітра 32 кольори
  Roles.cs              — ролі, назви, підказки, кольори, етапи
  GameState.cs          — глобальний стан (фаза, ім'я, роль, кімната, гравці), події
UI/
  ScreenRouter.cs       — перемикання екранів за фазою, toast
  UiSound.cs            — звуки інтерфейсу
  UiButtonFeedback.cs   — звук натискання/відмови, колір підпису за станом
  MainMenuScreen.cs, JoinRoomScreen.cs, LobbyScreen.cs,
  HeistPlaceholderScreen.cs, ResultScreen.cs
Backdrop/
  BackdropParallax.cs, LoopScroller.cs, Blinker.cs, NeonSign.cs,
  FlickerLight.cs, TrainPass.cs, SpriteSheetAnimator.cs,
  LightningController.cs, FlashlightSway.cs
Editor/
  BandaAssetSetup.cs    — налаштування імпорту (Point, без стиснення, PPU 1, нормалі),
                          шрифт TMP, сортувальні шари
  BandaSceneBuilder.cs  — збирає сцену Assets/Scenes/Main.unity повністю кодом

Сцена збирається командою меню: Banda → 2. Зібрати сцену Main
(ручні правки сцени при повторній збірці перезапишуться).

============================================================
5. ЩЕ НЕ ПЕРЕНЕСЕНО
============================================================
- Мережа (крок 2): пошук кімнати у Wi-Fi, підключення, перепідключення,
  авторитетний хост. Зараз кімната існує лише на одному пристрої — екрани кажуть про це прямо.
- Ролі й симуляція справи (крок 3): Хакер, Тінь, Зломщик, HeistSim, HUD.
- Тест датчиків, бенчмарк.
- Деталі фону: прожектор, гелікоптер, ворона, машини, пара, телевізор у вікні,
  ореол вивіски, тіні від банди, вогник цигарки й телефона.
- Світло налаштоване на око — без скріншота Godot-версії для порівняння.

Перевірити тільки на телефоні:
- напрямок паралаксу від нахилу (знаки осей),
- звук,
- чіткість піксельного шрифту на реальній роздільності.

============================================================
6. ЯК ЗАПУСТИТИ
============================================================
1. Project → Assets/Scenes/Main.unity → подвійний клік.
2. Game → роздільність 1920×1080 (або 16:9).
3. Play. Ввести ім'я, пройти цикл, поводити мишею (паралакс).
4. Блискавка одразу: CityBackdrop → LightningController → ⋮ → Strike now.
5. Якщо сцена зламалась: Banda → 2. Зібрати сцену Main.
