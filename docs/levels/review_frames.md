# Зафіксований набір кадрів для рецензії екрана Тіні

Набір незмінний між ітераціями: це вимірювальний інструмент, а не підгонка під оцінку.
Зафіксовано у коміті етапу 1 фінального проходу (листопад 2026). Змінювати — лише рішенням Івана, з новою точкою «до».

Відтворення (Unity, Play, справа запущена роллю Тіні, після зникнення повідомлення про мережу ~3 с):

```
Banda.EditorTools.ShadowReviewFrames.CaptureAll("Captures/unity/shadow_set")
python -I tools/art/review_sheet.py Captures/unity/shadow_set Captures/unity/shadow_set_sheet.png
```

Код набору — `Assets/Scripts/Editor/ShadowReviewFrames.cs` (дані нижче продубльовані там).

## Правила
- Координати — пікселі рівня (Y униз), `Center(x, y)` — центр тайла 16×16.
- Тінь і охоронець ставляться в симуляції й одразу у світ (без згладжування). Камера, сортування й rim рахуються
  звичайним `HeistWorldView.LateUpdate` — винос камери 48 px, межі арту як у грі.
- Охоронець видимий лише тоді, коли гра теж показала б його Тіні: відстань ≤ `ShadowViewRadius` (52 px).
- Тривога перед кожним кадром — 0%. Тінь не схована, без здобичі.
- Маршрут охоронця (`HeistLevel.CornerStore`): 0 (3,10) → 1 (14,10) → 2 (14,2) → 3 (1,2) → 4 (1,10).
