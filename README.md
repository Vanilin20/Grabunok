# Банда

Кооперативна гра про пограбування для 3–5 гравців. Кожен грає зі свого телефона й бачить лише свою роль: хакер, тінь, зломщик, відволікач, водій. Мета банди — не просто винести здобич, а прославитися на все місто.

- Рушій: Godot 4.7 (GDScript, рендерер Mobile)
- Платформа: Android (iOS пізніше)
- ТЗ: [`docs/TZ.md`](docs/TZ.md)

## Як запустити

1. Встанови [Godot 4.7](https://godotengine.org/download) (стандартна версія, не .NET).
2. Склонуй репозиторій і в Godot натисни **Import** → обери файл `project.godot`.
3. Натисни **F5** (Run Project).

## Статус

Етап 1 — технічний прототип (лобі, кімнати в локальній Wi-Fi, розподіл ролей).
