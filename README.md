# Банда

Кооперативна гра про пограбування для 3–5 гравців. Кожен грає зі свого телефона й бачить лише свою роль: хакер, тінь, зломщик, відволікач, водій. Мета банди — не просто винести здобич, а прославитися на все місто.

- Рушій: Godot 4.7 (GDScript, рендерер Mobile)
- Платформа: Android (iOS пізніше)
- ТЗ: [`docs/TZ.md`](docs/TZ.md)

## Як запустити

1. Встанови [Godot 4.7](https://godotengine.org/download) (стандартна версія, не .NET).
2. Склонуй репозиторій і в Godot натисни **Import** → обери файл `project.godot`.
3. Натисни **F5** (Run Project).

## Статус

Етап 1 — технічний прототип: лобі, кімнати в локальній Wi-Fi за кодом, розподіл ролей,
кожен телефон отримує свій екран, тест вібрації, гіроскопа й мікрофона.
Екрани ролей і «тестовий поверх» — **заглушки етапу 1** (позначені й у коді, і на екрані).

## Як тестувати на одному ПК

Кілька копій гри з різними іменами (токен відрізняє гравців, інакше копії вважаються одним телефоном):

```bash
godot --path . -- --name=Іван --token=pc1     # створи кімнату
godot --path . -- --name=Оля  --token=pc2     # приєднайся за кодом
```

На ПК: джойстик Тіні — мишею або WASD; диск Зломщика — мишею (на телефоні — поворотом), замість вібрації — спалах.

Швидкий перегляд екрана ролі без інших гравців: `godot --path . res://tests/preview_role.tscn -- --role=1` (0 Хакер, 1 Тінь, 2 Зломщик).

## Автотести

```bash
godot --headless --path . res://tests/smoke_scenes.tscn          # усі сцени відкриваються
# мережа: хост + 2 клієнти (кожен у своєму терміналі)
godot --headless --path . res://tests/net_bot.tscn -- --bot=host --token=t-host --name=Хост
godot --headless --path . res://tests/net_bot.tscn -- --bot=shadow --token=t-shadow --name=Тінь --discover
godot --headless --path . res://tests/net_bot.tscn -- --bot=safe --token=t-safe --name=Сейф
```

Мережевий тест перевіряє: пошук кімнати, ролі, що кожна роль бачить тільки своє, рух Тіні,
дії Хакера й Зломщика, обрив і повернення гравця посеред справи.

## Мережа

- ENet, порт **7777** (гра), UDP **7778** (пошук кімнати). Хост авторитетний.
- Якщо кімната не знаходиться за кодом (деякі роутери блокують broadcast) — введи IP хоста вручну, він показаний у лобі.
- Запасний варіант для публічних Wi-Fi — точка доступу з телефона хоста.

## Арт

Фон меню генерується скриптом `tools/art/gen_menu_city.py` (Python + Pillow) — палітра й розміщення правляться числами.
Шрифт — Press Start 2P (SIL OFL 1.1, `assets/fonts/press_start_2p_OFL.txt`), підтримує українську.
Палітра в `scripts/systems/palette.gd` — **тимчасова**, поки не закрите відкрите питання ТЗ про палітру й тайл.
